Autómata de un examen tipo test

Caso práctico

Juan prepara un examen de repaso de PHP para los nuevos de BK Programación: preguntas de cuatro opciones que se pueden saltar y contestar después. María quiere dos modos: uno que corrija cada pregunta en el momento (para aprender) y otro que solo dé la nota al final (para evaluarse). —Dos modos, preguntas saltadas, una lista de pendientes... —dice Carlos—. El botón Responder hace cinco cosas distintas según el caso.

1.- Enunciado

Programa en PHP un examen tipo test sin sesiones (el examen viaja en JSON en un campo oculto):

  • Se pide el nombre, el número de preguntas (5 o 10, del banco de preguntas) y el modo de corrección: después de cada pregunta o al final.
  • Cada pregunta tiene cuatro opciones y los botones Responder, Saltar y Entregar ya. Responder sin elegir opción muestra un aviso.
  • En el modo inmediato, tras responder se muestra si es correcta (y, si no, cuál era) con un botón Continuar.
  • Tras responder (o continuar, o saltar), se va a la siguiente pregunta sin responder. Si ya no quedan por delante pero hay preguntas saltadas, se muestra la revisión de pendientes, desde la que se puede ir a cualquiera (Ir a) o Entregar así. Si no queda ninguna, los resultados.
  • Resultados: aciertos, nota sobre 10 con un decimal, aprobado o suspenso, y cada pregunta con la respuesta dada (las no respondidas cuentan como fallo). Hacer otro examen vuelve a la configuración conservando el nombre.

2.- Análisis

  • Eventos entrantes. Ocho: Carga, Comenzar, Responder, Saltar, Continuar, Ir a (ir:3), Entregar y Repetir.
  • Estados. Seis: configuración, respondiendo, corrección inmediata, revisión de pendientes y resultados (más ST0).
  • Variables de estado. El examen: nombre, modo, número de preguntas, la respuesta de cada una (null si está sin responder) y la pregunta actual.
  • Dónde está la complejidad. Casi toda en a dónde se va después: tres predicados (PL7 "queda alguna sin responder por delante", PL8 "queda alguna sin responder" y PL6 "modo inmediato") deciden entre seguir preguntando, revisar o terminar. Los mismos PL7 y PL8 se usan en T3, T4 y T5.
  • Saltar siempre lleva a algún sitio. Si no hay más preguntas por delante, la que se acaba de saltar está pendiente: PL8 es seguro cierto y T4 no necesita el camino de "resultados".

4.4.- Comprobación de predicados (T3, con PL3 cierto)

PL7 y PL8 se calculan después de guardar la respuesta (AC5), así que no cuentan la pregunta actual; PL5 solo importa en el modo inmediato:

PL4 PL6 PL5 PL7 PL8 Camino
0 x x x x aviso, sigue en ST2
1 1 1 x x ST3 "¡Correcto!"
1 1 0 x x ST3 "Incorrecto"
1 0 x 1 x ST2, siguiente pendiente
1 0 x 0 1 ST4 revisión
1 0 x 0 0 ST5 resultados
Debes conocer

Aquí se ve una diferencia con los ejemplos anteriores: PL7 y PL8 se evalúan después de una acción (AC5, guardar la respuesta). Es correcto siempre que la tabla lo diga y el código respete ese orden. La alternativa, definirlos "sin contar la actual" antes de guardar, da lo mismo pero es más difícil de explicar. Escoge la forma que se entienda mejor y sé coherente en la tabla, el diagrama y el código.

5.- Del autómata al código

T3 en solucion/index.php (el camino !PL3 se resuelve antes del switch, para T3–T7 a la vez):

case 3:                                                // ---- T3 (ST2, Responder)
    $opcion = filter_var($_GET['opcion'] ?? '', FILTER_VALIDATE_INT, ['options' => ['min_range' => 0, 'max_range' => 3]]);   // AC4
    $i = $x['actual'];
    if ($opcion === false) {                           // PL3 && !PL4
        $estado = ST2;
        $examen = $x;
        es2($x, 'Elija una respuesta (o pulse Saltar).');
        break;
    }
    $x['respuestas'][$i] = $opcion;                    // AC5: guardar la respuesta
    $pl5 = $opcion === PREGUNTAS[$i][2];
    $siguiente = siguientePendiente($x, $i);
    if ($x['modo'] === 'inmediata') {                  // PL6
        $estado = ST3;                                 // PL3 && PL4 && PL6 && PL5 / !PL5
        $examen = $x;
        es3($x, $i, $pl5);
    } elseif ($siguiente !== null) {                   // PL3 && PL4 && !PL6 && PL7
        $estado = ST2;
        $x['actual'] = $siguiente;                     // AC6: ir a la siguiente pendiente
        $examen = $x;
        es2($x);
    } elseif (hayPendientes($x)) {                     // PL3 && PL4 && !PL6 && !PL7 && PL8
        $estado = ST4;
        $examen = $x;
        es4($x);
    } else {                                           // PL3 && PL4 && !PL6 && !PL7 && !PL8
        $estado = ST5;
        $examen = $x;
        es5($x);
    }
    break;

Las respuestas del banco de preguntas (7 % 3, intdiv(7, 2), "10" == "1e1", strlen("ñ"), 0 == "a" en PHP 8...) se comprobaron ejecutándolas en PHP 8.2.

7.- Para practicar

  • Añade un tiempo límite de 5 minutos: guarda la hora de inicio en el examen y comprueba en cada transición si se ha pasado. ¿Es un predicado nuevo que hay que añadir a todas las transiciones? ¿A qué estado se va si se ha agotado?
  • Permite cambiar una respuesta desde la revisión (no solo las pendientes). ¿Qué predicado cambia? ¿Y la lista de ES4?
