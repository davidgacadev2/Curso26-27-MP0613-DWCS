Autómata del Boletín 02, ejercicio 1: impuestos de las ventas

Caso práctico

Un comercial tiene que remitir cada mes un informe con el total de ventas y los impuestos que debe pagar: 5 % estatal y 4 % autonómico. Carlos tiene que hacer la página. Es el primer ejercicio con autómata, así que María le propone empezar por uno sencillo: dos campos, dos botones y tres páginas distintas.

1.- Enunciado

Desarrolla un script que introduzca la recaudación total mensual y el nombre del mes, y calcule los impuestos sobre la recaudación (5 % estatal y 4 % autonómico). Utilizar un formulario HTML para recoger los datos y mostrar los resultados (botón: calcular, botón: borrar). Ejemplo del boletín:

En la página Valor
Introduzca el importe mensual total de ventas 45678
Introduzca el nombre del mes Junio
Total recaudado 45678
Total líquido 41906
Impuestos (5 %) 2095,32
Impuestos (4 %) 1676,26
Impuestos totales 3771,58
Debes conocer

El ejemplo del boletín considera que la recaudación incluye los impuestos: el líquido es 45678 / 1,09 = 41906,42 y los impuestos se calculan sobre el líquido (41906,42 · 5 % = 2095,32). Así lo hace también la solución de los ejemplos del repositorio ($liquido = $total / (1 + 0,04 + 0,05)). Ojo: en el ejemplo del boletín las etiquetas están cambiadas: 2095,32 es el impuesto estatal (5 %) y 1676,26 el autonómico (4 %).

2.- Análisis

Caso práctico

Carlos dibuja en un papel las páginas que puede ver el usuario. Le salen tres: el formulario vacío, el formulario con un aviso en rojo y el formulario con la tabla de resultados.

  • Eventos entrantes. Los dos botones son submit y llegan al servidor: Calcular y Borrar. La primera carga de la página (sin parámetros) hace lo mismo que Borrar: mostrar el formulario vacío.
  • Eventos salientes. Tres variantes de la página: vacía, con avisos y con resultados.
  • Estados. Solo dos: ST0 (la página aún no se ha mostrado) y ST1 (el formulario está a la vista, esperando datos). Al calcular, la página vuelve a esperar datos: no hace falta un estado "resultados" porque desde ahí el usuario puede hacer lo mismo que desde el formulario vacío.
  • Predicados. Dos condiciones atómicas: el importe es un número mayor que 0 y el mes es uno de los doce (aunque llegue de un <select>, se puede manipular).
  • Acciones previas. Para evaluar los predicados primero hay que limpiar y validar las entradas (AC0, AC1).

En cada fila hay exactamente un 1: los dos caminos son completos (siempre se cumple uno) y excluyentes (nunca los dos).

5.- Del autómata al código

La solución completa está en solucion/index.php. La tabla de eventos-estados es un array y cada transición, un case; los predicados son variables con su nombre:

$automata = [
    ST0 => [EE0 => 1, EE1 => 1],
    ST1 => [EE0 => 2, EE1 => 1],
];
$evento = ($_GET['evento'] ?? '') === 'calcular' ? EE0 : EE1;   // cualquier otra cosa cuenta como Borrar

switch ($automata[$estado][$evento]) {
    case 1:                                                // ---- T1
        $estado = ST1;
        es0();
        break;
    case 2:                                                // ---- T2
        $importeEscrito = trim((string) ($_GET['importe'] ?? ''));                 // AC0
        $importe = filter_var(str_replace(',', '.', $importeEscrito), FILTER_VALIDATE_FLOAT);
        $mes = (string) ($_GET['mes'] ?? '');                                      // AC1
        $pl0 = $importe !== false && $importe > 0;
        $pl1 = in_array($mes, MESES, true);
        if (!$pl0 || !$pl1) {                              // !PL0 || !PL1
            $estado = ST1;
            // AC6: $errores['importe'] / $errores['mes']
            es1($importeEscrito, $pl1 ? $mes : MESES[0], $errores);
        } else {                                           // PL0 && PL1
            $estado = ST1;
            $liquido = $importe / (1 + IMPUESTO_ESTATAL + IMPUESTO_AUTONOMICO);    // AC2
            $estatal = $liquido * IMPUESTO_ESTATAL;                                  // AC3
            $autonomico = $liquido * IMPUESTO_AUTONOMICO;                            // AC4
            $impuestos = $estatal + $autonomico;                                     // AC5
            es2($importeEscrito, $mes, $importe, $liquido, $estatal, $autonomico, $impuestos);
        }
        break;
}

Recomendación

Compara esta solución con la de los ejemplos del repositorio para el Boletín 02-E01 (no incluida en este material): allí el "estado" es una variable primeraVez en un campo oculto y la decisión se reparte entre varios if a lo largo de la página. El autómata obliga a separar qué se comprueba (PL0, PL1) de qué se hace (AC2–AC5) y de qué se muestra (ES0–ES2).

7.- Para practicar

  • Añade un tercer botón, Ejemplo, que rellene el formulario con 45678 y Junio. ¿Es un evento nuevo? ¿Necesita un estado nuevo? Añade la columna a la tabla de eventos-estados y su transición.
  • El boletín pide que el importe sea un número. Añade el predicado "el importe tiene como mucho 2 decimales" y rehaz la comprobación de predicados de T2 (ahora con 3 predicados: 8 filas).
