Autómata del Boletín 03, ejercicio 8: ¿qué día de la semana es?

Caso práctico

La web del Bar Baio quiere un pequeño calendario: el cliente escribe una fecha y la página le dice qué día de la semana es. Carlos ve enseguida que la página tiene un solo formulario, pero muchas formas de equivocarse: un año fuera de rango, un mes 13, un 31 de abril, un 29 de febrero de un año que no es bisiesto...

1.- Enunciado

Desarrolla un script que solicite un número de año (1–3000), mes (1–12) y día (1–31) e indique qué día de la semana, como cadena de texto ("lunes", ..., "domingo"), sería. Utiliza la expresión de Michael Keith y Tom Craver:

(d+=m<3?y--:y-2,23*m/9+d+4+y/4-y/100+y/400)%7

donde d = día, y = año y m = mes. La expresión devuelve un número entre 0 y 6, donde 0 = domingo, 1 = lunes... 6 = sábado. El script debe comprobar que la entrada es correcta: que el día del mes es válido para el mes indicado. Recuerda que un año es bisiesto si es divisible por 4 pero no por 100, o si es divisible por 400.

Debes conocer

La expresión está escrita en C: las divisiones son enteras (en PHP, intdiv), y d += m < 3 ? y-- : y-2 significa "si el mes es enero o febrero, suma a d el año y después réstale 1 al año; si no, suma a d el año menos 2". Con esa traducción, la fórmula da el mismo resultado que DateTime::format('w') para todas las fechas probadas, también el año 1 (calendario gregoriano extendido hacia atrás).

2.- Análisis

  • Eventos entrantes. Enviar (un submit) y la carga de la página sin parámetros. El botón Borrar es un <button type="reset">: lo resuelve el navegador vaciando los campos, no llega al servidor.
  • Eventos salientes. Cuatro variantes: formulario vacío, con avisos de rango, con el aviso "ese día no existe en ese mes" y con el resultado.
  • Estados. ST0 y ST1, como en el ejercicio anterior: tras cada respuesta la página vuelve a esperar una fecha.
  • Predicados. Tres de rango (año, mes, día) y uno más: el día existe en ese mes de ese año. Este último solo se puede calcular si los tres primeros son ciertos (para saber cuántos días tiene el mes hay que conocer un mes válido y, para febrero, un año válido).
  • Acciones previas. Limpiar y validar los tres campos (AC0, AC1, AC2).

4.4.- Comprobación de predicados (T2)

Con cuatro predicados habría 16 combinaciones, pero PL3 no se evalúa si alguno de los tres primeros es falso (se escribe x: da igual su valor). Quedan 9 filas:

PL0 PL1 PL2 PL3 (a) (b) (c)
0 0 0 x 1 0 0
0 0 1 x 1 0 0
0 1 0 x 1 0 0
0 1 1 x 1 0 0
1 0 0 x 1 0 0
1 0 1 x 1 0 0
1 1 0 x 1 0 0
1 1 1 0 0 1 0
1 1 1 1 0 0 1

Un 1 en cada fila: completos y excluyentes. La x se traduce en el código en el orden de las condiciones: PL3 va después de comprobar PL0, PL1 y PL2, en un elseif (o detrás de ellos en un &&), así nunca se llama a diasDelMes() con un mes 13.

5.- Del autómata al código

Fragmento de solucion/index.php:

case 2:                                                    // ---- T2
    // AC0, AC1, AC2: limpiar y validar
    $anio = filter_var($valores['anio'], FILTER_VALIDATE_INT, ['options' => ['min_range' => 1, 'max_range' => 3000]]);
    $mes = filter_var($valores['mes'], FILTER_VALIDATE_INT, ['options' => ['min_range' => 1, 'max_range' => 12]]);
    $dia = filter_var($valores['dia'], FILTER_VALIDATE_INT, ['options' => ['min_range' => 1, 'max_range' => 31]]);
    $pl0 = $anio !== false;
    $pl1 = $mes !== false;
    $pl2 = $dia !== false;

    if (!$pl0 || !$pl1 || !$pl2) {                         // (a)
        $estado = ST1;
        // AC5: un aviso por cada campo fuera de rango
        es1($valores, $errores);
    } elseif ($dia > diasDelMes($mes, $anio)) {            // (b): PL0 && PL1 && PL2 && !PL3
        $estado = ST1;
        es2($valores, $mes, $anio, diasDelMes($mes, $anio));
    } else {                                               // (c): PL0 && PL1 && PL2 && PL3
        $estado = ST1;
        $diaSemana = diaDeLaSemana($dia, $mes, $anio);     // AC6
        $nombreDia = DIAS[$diaSemana];                     // AC7
        es3($valores, $dia, $mes, $anio, $nombreDia);
    }
    break;
function diaDeLaSemana(int $dia, int $mes, int $anio): int     // AC6
{
    if ($mes < 3) {
        $dia += $anio;                     // y-- : se suma el año y DESPUÉS se resta 1
        $anio--;
    } else {
        $dia += $anio - 2;
    }
    return (intdiv(23 * $mes, 9) + $dia + 4 + intdiv($anio, 4) - intdiv($anio, 100) + intdiv($anio, 400)) % 7;
}
